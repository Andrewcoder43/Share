# Share

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Last Updated](https://img.shields.io/github/last-commit/Andrewcoder43/Share)](https://github.com/Andrewcoder43/Share/commits/main)

Share is a React application that provides users with over 59 different ways to share the current page. This project was created to offer a variety of sharing options in a single, easy-to-use interface.

## Features

- **Multiple Sharing Options**: Provides over 59 different ways to share the current page.
- **React-based**: Built using React for a fast and responsive user experience.
- **Easy to Use**: Simple and intuitive interface for effortless sharing.

## Installation

To get the Share project up and running on your local machine, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/Andrewcoder43/Share.git
    cd Share
    ```

2.  **Install the dependencies:**

    ```bash
    npm install
    ```

## Usage

1.  **Start the development server:**

    ```bash
    npm start
    ```

    This will start the application in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

2.  **Build the project for production:**

    ```bash
    npm run build
    ```

    This will create a `build` directory with the production-ready files.

3.  **Deploy to GitHub Pages (optional):**

    ```bash
    npm run deploy
    ```

    Make sure you have the `gh-pages` package installed as a dev dependency. This command will deploy the contents of the `build` directory to your GitHub Pages.
